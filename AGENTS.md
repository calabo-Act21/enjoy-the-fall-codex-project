# AGENTS.md — Enjoy The Fall website

## Mission

Build the official Enjoy The Fall showcase website.

## Read first, in this order

1. `MASTER-PROMPT-ENJOY-THE-FALL.md`
2. `DESIGN-SYSTEM.md`
3. `source-material/EPK-Enjoy-The-Fall.pdf`
4. Inspect the supplied source photographs/logo in `source-material/assets/`
5. Only if useful, inspect `source-material/old-prototype/`

## Non-negotiable rules

- Build the production site in `site/`.
- Do not overwrite files in `source-material/`.
- The EPK is the factual/content source of truth.
- The old prototype is **not** a design reference. Preserve only the palette and fonts documented in `DESIGN-SYSTEM.md`.
- Royal Republic may inspire structure/editorial rhythm, but do not clone it.
- Use semantic HTML, modern CSS and vanilla JavaScript.
- Do not invent missing factual information, URLs, dates, quotes, ticket links or release data.
- Use the supplied photographs rather than AI-generated replacements.
- Test responsive behavior, accessibility, links, video switching, metadata and structured data before finishing.
- Keep the final site easy for a non-expert to maintain.

## Deliverables

All final production files belong in `site/`.

At the end, provide:
- a short summary of what was built;
- any remaining TODOs that genuinely require user input;
- instructions to preview locally;
- deployment-ready notes.
