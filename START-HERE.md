# START HERE — Enjoy The Fall × Codex

Ce dossier est prêt à être ouvert comme projet Codex.

## Option la plus simple

1. Dézippe ce dossier.
2. Ouvre un terminal dans le dossier `enjoy-the-fall-codex-project`.
3. Lance :

```bash
codex
```

4. Colle le contenu de `CODEX-FIRST-PROMPT.txt` comme premier message.

Codex doit lire automatiquement `AGENTS.md`, mais le premier prompt lui demande aussi explicitement de le faire.

## Où Codex doit travailler

Le site final doit être généré dans :

```text
site/
```

Les fichiers présents dans :

```text
source-material/
```

sont des sources et références. Ils ne doivent pas être écrasés.

## Contenu du package

- `AGENTS.md` : règles courtes destinées à l'agent.
- `MASTER-PROMPT-ENJOY-THE-FALL.md` : brief de production complet.
- `DESIGN-SYSTEM.md` : palette, typographies et règles visuelles.
- `source-material/EPK-Enjoy-The-Fall.pdf` : source de vérité pour le contenu.
- `source-material/assets/` : logo + 3 photos sélectionnées.
- `source-material/old-prototype/` : ancien essai HTML/CSS/JS, uniquement pour contexte historique.
- `site/` : dossier dans lequel Codex doit construire le site.

## Conseil

Laisse Codex effectuer une première passe complète, lui faire ouvrir/inspecter le rendu en desktop + mobile, puis demande-lui une seconde passe de finition visuelle avant de valider.
